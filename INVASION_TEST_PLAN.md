# INVASION (experimental)
Default retains 5 x 7 and original victory rules. Invasion uses 9 x 9, cumulative 3 units reaching the opponent's farthest row by regular movement, no kill victory. Units that score leave the board. Room and match documents carry gameMode; old rooms default to DEFAULT. Join follows creator.
Fence: 2 mana, length 2 edges, 3 active per player, one build per turn, 20 HP. A nearby living friendly unit permits 10 damage for 1 mana. Both sides may damage a fence. Normal movement and knockback blocked; spatial card effects may bypass walls but cannot directly score. Reject overlapping/crossing fences and closures that disconnect a starting cell or currently living unit from the goal (ignoring other units). CPU uses shortest wall-aware distance and avoids blocked movement; CPU construction/destruction strategy is not implemented.
Run node --test tests/invasion_rules.test.mjs. Before Firebase release: check deployed rules permit new room/match/state fields; test two clients with default/invasion, reconnect, CPU, B perspective, fence selection and removal, all spatial/EX effects, mobile layout, victory/history, exhausted deck and panic stalemate. Do not release without these checks.
